MY MEMORY GAMES - how to finish your site
==========================================

1. Open index.html (the cover page) in your browser. START THE GAME leads to menu.html, the page with the 8 rounds.
2. Add your pictures to the "images" folder using these exact names (.jpg):
     childhood-1 ... childhood-5
     family-1 ... family-5
     friends-1 ... friends-5
     love-1 ... love-5
     food-1 ... food-3
   Optional: movie-poster.jpg, song-cover.jpg
   Until a picture exists, a "Add your photo" placeholder shows its file name.
3. Add your videos to the "media" folder:
     movie-clip.mp4   (your favorite movie clip)
     karaoke.mp4      (karaoke version of your song)
4. Open each page (childhood.html, family.html, ...) in a text editor and replace
   everything in [square brackets] with your own words: captions, synopsis, cast,
   characters, recipe, your song's story and your 5 jokes.
5. Replace [YOUR NAME] in index.html.

To put it online for free: upload the whole folder to Netlify Drop, GitHub Pages or Cloudflare Pages.
